Video Wallpaper Plugin v1.6 for iNextOS / RoceOS

Install: bash install.sh
Uninstall: bash uninstall.sh
Access: http://192.168.100.1:8686

Features:
- Video background for login page
- Adjustable opacity, mute toggle
- Upload/delete videos
- Custom video path with directory browser
- Create new folders in browser
- Full filesystem access
- Auto desktop shortcut creation
- Auto recovery after system update
- LIVE WALLPAPER SWITCH (v1.6): click a video in manager, wallpaper changes instantly without page refresh
- VIDEO THUMBNAILS (v1.6): auto-generate preview image for each video

See 视频壁纸插件说明书.md for full documentation (Chinese/English).
